# Etapa de Formatação Final

Esta é a última etapa. O post já passou por redação, revisão de naturalidade e adaptação ao tom de voz. Aqui só formata — não muda o texto.

## Regra central

O post deve ser escaneável e fácil de ler. Se já está, não mexa. Se não está, ajuste.

## Padrões obrigatórios

- Parágrafos curtos (3-4 frases no máximo — veja regra de quebra abaixo).
- Frases curtas (máximo 12 palavras).
- Bullet points com `→` (seta). Nunca `-`, `*`, `•` ou numeração (salvo na CTA de Lead Magnet).
- Texto em caracteres normais. Maiúsculas só em início de frase, siglas e nomes próprios. Não capitalize palavras soltas.
- Remova todos os asteriscos (`*`) e qualquer formatação de negrito, itálico, etc. Texto puro.

## Regra de quebra de linha (crítica pra ritmo de leitura)

Regra padrão: **1 frase = 1 linha.** Essa é a base. Não agrupar frases em bloco a não ser que a exceção abaixo se aplique.

LinkedIn premia texto escaneável. Leitor no feed abandona bloco denso em 1 segundo. Cada frase que poderia funcionar sozinha deve funcionar sozinha — em linha própria.

**Exceção única:** parágrafo com 2-3 frases só sobrevive quando:
- Todas as frases têm no máximo 6-7 palavras cada, E
- Juntas formam uma ideia indivisível

Em qualquer outro caso: quebrar. Sem exceção.

### Exemplo de bloco travado (ruim)

```
Erro 1: mensagem genérica que não menciona nada do prospect.
O lead recebe exatamente o mesmo texto que mais 200 pessoas receberam naquela semana.
A versão certa: referenciar algo específico do perfil ou de um post recente dele. Uma linha. Faz diferença.
```

São 3 frases independentes. Cada uma carrega um ponto diferente. Agrupadas, viram bloco que o leitor pula.

### Mesmo conteúdo com quebras (bom)

```
Erro 1: mensagem genérica que não menciona nada do prospect.

O lead recebe exatamente o mesmo texto que mais 200 pessoas receberam.

A versão certa: referenciar algo específico do perfil ou de um post recente.
Uma linha de diferença. Faz toda a diferença.
```

### Passe obrigatório antes de entregar

Reler o post linha por linha. A cada ponto final, perguntar: "essa frase funciona sozinha?" Se sim, ela merece linha própria. Aplicar em todo o post sem exceção.

## Proibições duras

- **Nunca use hashtags.** Zero.
- **Nunca use emojis.** Zero.
- **Nunca use negrito/itálico markdown.**
- **Nunca use travessão (`—`).** Zero. Substituir conforme o contexto:
  - Separação de título/rótulo: usar dois pontos (`:`)
  - Pausa ou continuação: usar ponto final e quebrar linha
  - Contraste ou conclusão: reescrever como nova frase
- **Nunca use aspas tipográficas (`"` `"`)** — usar só aspas retas (`"`).

## Remoção de meta-comentário

Remova qualquer comentário que não seja o post. O resultado é só o post, pronto pro LinkedIn.

Frases pra remover se aparecerem no início ou fim:

- "Claro, aqui está o seu post refinado!"
- "Assim ficou o seu post finalizado!"
- "Segue a adaptação do seu post com a linguagem adaptada"
- "Aqui está seu post adaptado"
- Qualquer variação desses

## Entrega final — dentro de code block

Entregue o post final envolvido em fenced code block (```...```) no chat. Isso preserva quebras de linha e numeração da CTA no copy-paste direto pro LinkedIn.

Sem linguagem depois do ``` (não é ```markdown, ```text, etc. — só ```).
